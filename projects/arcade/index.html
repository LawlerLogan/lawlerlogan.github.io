Mini Arcade Machine

High school senior capstone: a wooden arcade machine running a Galaga-style shooter written from scratch in Godot on a Raspberry Pi 5.

Context
Mechatronics II capstone, CSI, 2025
Hardware
Raspberry Pi 5, 7-inch display, 3 arcade buttons
Software
Godot, Python (gpiozero, evdev)
Build
Machined wood cabinet
Skills
  • Mechanical & CAD
  • Software
  • Electronics
  • Fabrication

Proposal and review

The project started as a written proposal: a game built in Godot, running on a Raspberry Pi 5 and played through buttons on its GPIO pins. Before building, it was pitched to a panel of five industry reviewers. Their notes, to keep it an old-school game with a high score, simple inputs and an easy startup, set the requirements for the build.

Researching the game

Before writing any game code, a research paper broke Galaga down into its core mechanics and chose how to rebuild each one in Godot:

  • Shooting: each shot is spawned as its own projectile that travels at a set speed and only hits on contact. An instant ray cast was ruled out because it could count a hit on an enemy that had already moved away. Shots that leave the screen are cleared to save performance
  • Movement: Godot's standard eight-direction movement cut down to left and right only
  • Enemies: waves that fly in along spline paths to set slots on a grid above the player, growing with each round
  • Scoring: points per enemy, with a high score that updates whenever it is beaten
  • Visuals: pixel-art sprites over a starfield made with a particle system, randomized so it reads as motion through space

Buttons to keystrokes

Godot reads the keyboard, and arcade buttons aren't a keyboard. The fix is a small Python service that makes them one:

  • Three buttons are wired to the Pi's GPIO pins (2, 3 and 10) and read with gpiozero
  • evdev's UInput creates a virtual keyboard at the Linux input layer, so the game receives real key events with no changes to the game code
  • Left and right hold their keys for as long as the button is down; fire sends a single tap per press, so holding it doesn't machine-gun
  • The loop polls every 10 ms and only sends an event when a button changes state

The cabinet

The electronics were proven first on a breadboard with the Pi, display and buttons in January 2025. The cabinet was sketched, then modeled in CAD with drawings for the cabinet and its arcade buttons, and built from machined wood by April. It houses the Pi, a 7-inch display and the three buttons, and boots straight into the game.

Result

The finished machine met every goal set in the proposal. The game was tuned for a crowd: short turns of about three minutes, then hand it to the next person to beat the score, with difficulty climbing sharply around wave 12. In the first playtest, a high score of about 23,000 on wave 13 was beaten by the very next player with 28,000 on wave 14, the back-and-forth it was designed for.

It was presented at the 2025 CSI capstone showcase alongside a display board covering the cabinet, electronics and software, and a full engineering notebook documenting the proposal, research, design, prototypes and testing. The notebook also lists the next steps: a joystick for finer control, more games to choose from, a faster boot and a painted cabinet.
