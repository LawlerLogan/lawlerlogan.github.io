Mini Arcade Machine

High school senior capstone: a wooden arcade machine running a Galaga-style shooter written from scratch in Godot on a Raspberry Pi 5.

Context
Mechatronics capstone, 2025
Hardware
Raspberry Pi 5, 7-inch display, 3 arcade buttons
Software
Godot, Python (gpiozero, evdev)
Build
Machined wood cabinet
Skills
  • Software
  • Electronics
  • Fabrication

The game

A Galaga-style space shooter written from the ground up in Godot: the player ship, enemies, shooting and scoring, all built without templates and tuned to be played on three buttons.

Buttons to keystrokes

Godot reads the keyboard, and arcade buttons aren't a keyboard. The fix is a small Python service that makes them one:

  • Three buttons are wired to the Pi's GPIO pins (2, 3 and 10) and read with gpiozero
  • evdev's UInput creates a virtual keyboard at the Linux input layer, so the game receives real key events with no changes to the game code
  • Left and right hold their keys for as long as the button is down; fire sends a single tap per press, so holding it doesn't machine-gun
  • The loop polls every 10 ms and only sends an event when a button changes state

The cabinet

A compact cabinet machined from wood, housing the Raspberry Pi 5, a 7-inch display and the three arcade buttons, so the machine boots straight into the game and plays standalone.

Showcase

Presented at the 2025 mechatronics capstone showcase alongside a display board covering the cabinet, electronics and software, and a full engineering notebook documenting the build.
